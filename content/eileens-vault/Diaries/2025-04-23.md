- Web 端
- 免费版传书上限10本
- 手机上搭配 Safari 的 reader mode

因为这个网站的阅读器没有中文字体，我用一个叫 Stylus 的 extension 将中文字体覆盖为宋体，以下是 ChatGPT 帮我写的代码：

```
@-moz-document domain("bookfusion.com") {
  *:lang(zh), *:lang(zh-CN), *:lang(zh-Hans), *:lang(zh-Hant), *:lang(zh-TW), *:lang(zh-HK) {
    font-family: "SimSun", "宋体", serif !important;
  }
}
```
