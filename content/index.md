This website contains Eileen Gao's AP Notes. Navigate across notes using either the explorer or internal links and within notes using the table of contents.

这些是我个人在学习 CSA 时整理的笔记，对于难点和考试中的易错点记录比较详细，基础部分较为简洁。如果需要关于 primitive types, using objects, boolean expressions & if-statements, 和 iteration 的完整课程，请访问 [Bill Barnum 的视频列表](https://www.youtube.com/playlist?list=PLmpmyPywZ440vPqpAPeUkE-TeKifbS45W)。

考试的时候允许参考 [Java Quick Reference](https://apcentral.collegeboard.org/media/pdf/ap-computer-science-a-java-quick-reference.pdf)。参考里对每个内置方法的作用介绍得很清晰，笔记里没有过多赘述，**特别需要注意的是 [[03-ArrayList#Comparison of String, Array, and Arraylist|String, Array, 和 ArrayList 三个类中提取元素和长度的方法之间的对比]]。[[01-Basics#Common Algorithms|01]], [[02-Array#Common Algorithms|02]], [[03-ArrayList#Common Algorithms|03]] 笔记中的 Common Algorithms 需要记忆，考试中一定会遇到。**

2026年的 AP CSA 考试将会使用新的课程大纲，删除了 inheritance 和 recursion 的章节，新增了 text files 和 data sets （新增部分的笔记未来会更新，stay tuned）。课程和考试的变化看[这里](https://apcentral.collegeboard.org/courses/ap-computer-science-a/future-revisions)。完整的课程大纲看[这里](https://apcentral.collegeboard.org/media/pdf/ap-computer-science-a-course-and-exam-description.pdf)。

由于笔记写成之初并未考虑到发表的需求，部分表述不清晰，欢迎微信讨论和建议。
